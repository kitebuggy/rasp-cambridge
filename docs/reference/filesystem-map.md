## What is allowed at the repo root

`README.md`, `AI_README.md`, `LICENSE`, `requirements.txt`,
`rasp_stars.py`, `.gitignore` - nothing else. Docs go in `docs/`,
generated output goes under `public/` (CI) or `out/` (local). AI sessions
must not leave scratch or backup files anywhere in the repo (AI_README
Critical rule 6).
